# Memory Taxonomy

## Global user memory examples

- "Prefers concise responses with bullet points."
- "Works in sales ops and prioritizes outbound conversion metrics."
- "Avoids emojis in customer-facing copy."

## Project memory examples

- "Project uses athlete outreach for endurance brands only."
- "Current campaign targets Q3 hydration launch."
- "Use company short-name 'TT' instead of full legal entity."

## Session-only examples (do not persist)

- "Draft two alternatives for this prompt."
- "Use web search for this turn."
- "Respond under 120 words this time."
